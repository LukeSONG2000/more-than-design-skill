# Web 重点交互模式

范围：Web 行为，不规定品牌样式或弹簧/模糊参数。核对日期：2026-11-03。组件命名随库变化；先确定任务合同，再核对项目锁定版本的 API。

## 浮层：先决定能否操作背景

| 任务条件 | 推荐方向 | 必须确定 |
|---|---|---|
| 短任务必须先处理 | Modal dialog | 初始焦点、模态背景、关闭/取消、焦点恢复 |
| 重要且有后果的决定 | Alert dialog 或确认 Dialog | 对象、后果、取消与执行明确分开；不要默认聚焦破坏性动作 |
| 原内容与详情需同时操作 | 非模态详情区 / Split pane | 自然 Tab 顺序，不锁背景、不困住焦点 |
| 锚定对象上的短编辑 | Popover | 标签、焦点、边界碰撞、保存/取消；长任务转页 |
| 对象命令集合 | Menu | 方向键、激活、关闭、禁用项与触摸入口 |
| 移动 Web 的上下文内容 | Bottom sheet | 模态性、展开容量、软键盘、内部滚动、拖动之外的关闭方式 |

[APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)定义模态焦点与 Esc 关闭路径；焦点返回触发点或合理的后续位置。[Radix Alert Dialog](https://www.radix-ui.com/primitives/docs/components/alert-dialog)也支持 Esc。取消关闭不等于确认危险操作，不能把“危险”翻译成无法退出。

工程规则：关闭手势不能静默丢弃草稿；必要时保留草稿或提示保存/放弃。异步提交中区分取消请求和关闭展示，不能假装关闭会撤销已提交操作。避免叠加多层模态；真的需要嵌套时验证最上层焦点、关闭顺序和背景隔离。

[HTML popover](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover)提供展示机制，不自动选择业务语义。原生 HTML、库 Dialog 或自定义非模态面板按需求选择，不靠蒙层外观决定 `aria-modal`。移动 Web 不自动获得 UIKit/Compose 的系统 Sheet 行为。

## 反馈：按持续性与恢复能力选择

- 普通成功：局部状态更新通常足够，可加非打断 Toast。频繁成功不要连续抢读屏焦点。
- 可撤销删除：先核实后台支持和撤销期限；反馈带 Undo，超时后仍需适当的回收站/历史恢复方案或明确限制。撤销失败显示真实结果。
- 永久删除：确认对象、数量、后果与权限，提供取消。不能因为 Snackbar 更简洁就省略风险控制。
- 字段错误：保留输入，在字段旁持续展示并关联；提交失败可给可导航的错误摘要。错误仍在就不因计时自动清除。
- 全局离线/权限/服务故障：持久 Banner 或错误页，并保留任务状态。无权限不是空数据，加载失败不是零结果。
- 无法确定时长：显示不定进度；只有支持真实取消时才提供取消动作，否则区分关闭展示与停止执行。只有可测量才显示百分比。后台任务完成后给可找回结果入口。

以上为场景归纳。辅助依据：[APG Alert](https://www.w3.org/WAI/ARIA/apg/patterns/alert/)、[WAI 表单通知](https://www.w3.org/WAI/tutorials/forms/notifications/)。消息需按紧迫性使用适当 live region，避免每次输入重复播报。

## 表单和搜索

简单、可用的原生 HTML 控件优先评估；只有样式或行为确需时才引入复合控件。标签、帮助、单位、错误分工明确，不把减少文字变成取消标签。

搜索候选用 Combobox 时区分“选已有对象”和“允许创建新对象”。显示加载、无结果、失败与重试；处理请求乱序、输入法组合输入、清空和键盘选择。输入中的暂态不立即显示惩罚性错误。

筛选区区分即时生效与统一 Apply，保留已选条件、清空、结果计数。适合分享/恢复的条件写入 URL，但不将敏感数据写进地址。服务端分页的排序、过滤、全选范围与导出范围必须一致且明确；批量操作不能默认为未加载记录。

相关模式：[APG Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)、[WAI Forms](https://www.w3.org/WAI/tutorials/forms/)。

## 列表与详情

宽屏频繁比较优先分栏，短编辑可用 Drawer，复杂编辑/可分享对象优先独立路由。Drawer 只是承载方式，不意味着每次编辑都必须覆盖主页面。

窄屏根据内容转页或全高面板；保存记录 ID、筛选、分页、滚动和草稿。深链接打开、刷新、浏览器返回、删除当前记录、权限失效均有明确去向。容器扩缩过程中不重复提交，不丢焦点，不把详情误切到另一条记录。

静态数据优先语义表格；真正需要单元格导航/编辑时评估 Data grid，不能给普通表格添加 `role=grid` 就当作完成键盘支持。大数据再评估虚拟化，它会增加焦点、读屏、定位和打印复杂度。

相关模式：[APG Table](https://www.w3.org/WAI/ARIA/apg/patterns/table/)、[APG Grid](https://www.w3.org/WAI/ARIA/apg/patterns/grid/)。

## 交付检查

每次只测试涉及的路径：触发、默认态、加载、空、错误、禁用/无权限、提交中、成功、关闭/返回、恢复；另测键盘、触摸、读屏名称、文字缩放、窄容器和减少动态。测试清单不是测试通过证明；没有浏览器/辅助技术实测时明确标为待验证。
