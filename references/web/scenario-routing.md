# Web 场景决策

范围：浏览器中的产品界面，包括移动 Web。官方资料核对日期：2026-11-03。下列维度是本 skill 的工程归纳，适用于需要澄清组件、交互或业务风险的任务。局部样式修改和明确的组件需求可直接基于现有实现完成。

## 用户说目标，AI 选择交互

从用户描述的目标理解任务，按当前问题读取必要的页面或实现。保留业务意图，涉及目标变更、危险操作或范围扩展时取得授权。以下维度选择与问题有关的部分；HIG 审美贯穿实现。

1. 任务：浏览、定位、比较、输入、选择、执行命令、确认风险还是查看进度？
2. 风险：操作能否真正撤销，有无金钱、权限、数据丢失影响？不确定时不能假设可逆。
3. 上下文：用户需继续看或操作原内容，还是进入独立任务？要不要链接、刷新恢复、前进后退？
4. 容量：字段数量、信息长度、数据规模、并行比较与操作频率；管理系统保留有效密度。
5. 环境：实际容器可用空间、触摸/键盘/指针、软键盘、文字缩放、网络与权限。
6. 选择：查名称或替代方案时读[组件地图](component-atlas.md)，补行为契约时读[交互模式](interaction-patterns.md)；样式与动效独立处理，按实现需要安排。

已有信息足够时直接给出一个推荐并实现，不让用户从十几个术语里做选择。缺失信息只有在改变风险、数据正确性、核心流程或技术选型时才询问。低风险可逆的外观细节自行选合理默认。对用户用一句话说明收益，可附术语帮助学习，不在产品里增加教学副标题。

## 口语到场景

| 用户说法 | 首选方向 | 改变选择的条件 |
|---|---|---|
| “下面拉起来看评论，别丢掉视频” | Bottom Sheet 底部面板 | 是否可继续操作视频决定模态性；键盘和长评论决定展开高度，不固定三档百分比 |
| “点订单看看，别离开列表” | 并排详情面板或侧边 Drawer | 宽屏频繁比较用非模态分栏；窄屏完整详情页或短任务浮层，保留筛选与滚动 |
| “点这三个点处理这条记录” | Menu 操作菜单 | 输入字段不是菜单项；编辑用 Popover、表单或详情页 |
| “删错了可以恢复” | 执行后持久可找的撤销入口，可附 Snackbar | 必须有真实撤销能力；不可逆或影响他人时先确认，不用视觉假撤销 |
| “这个填写错了，告诉我哪里错” | Field error 字段错误，提交时可加错误摘要 | 不用几秒后消失的 Toast 作为唯一错误来源 |
| “有几万条，要按多个条件查” | 搜索、组合筛选、结果表格、分页或虚拟化 | 明确服务端查询/排序范围；不能仅在已加载页筛选却声称全量 |
| “让我快速找到并执行操作” | Command Palette 命令面板 | 普通浏览保留可发现入口；不能只提供快捷键 |
| “展示增长情况，还要查准确数字” | 图表与可访问的数据表/摘要 | 单个数字用指标，精确比较用表格，不为视觉效果强加图表 |
| “设置太多，但大多数人只改几个” | 主设置 + Disclosure/高级选项 | 必填、错误和关键风险不藏在折叠区；复杂跨页过程才考虑 Wizard |

## 选择合同

涉及新的交互决策时，明确相关任务、组件理由、风险与必要验收路径；按影响范围补状态、退出、恢复或窄屏变化。说明的详略与任务复杂度匹配，简单修改可直接交付结果。

窗口变化时保持 URL、表单草稿、返回位置和选中记录连续；从桌面非模态详情切换到窄屏时，根据内容容量选择呈现方式，并明确焦点和背景可操作性。

## 依据和边界

- [WAI-ARIA APG 模式](https://www.w3.org/WAI/ARIA/apg/patterns/)用于语义与交互依据；APG 是实现指导，不等于自动通过 WCAG。
- [LearnUI](https://learnui.qiaomu.ai/)可做视觉词典和发现入口，不能代替标准或组件库当前 API。
- 图片、社交文章中的固定尺寸和绝对规则仅作线索；没有核验的内容不写成标准。
- 新增未知形态时记录任务、适用/禁用条件、状态、实现来源、核验日期与未验证项，再接入地图。不要宣称穷尽所有组件。
